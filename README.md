# bambi.byleigh storefront design

A static storefront recreated from the reference site for bambi.byleigh.

Included:
- Home landing page
- Product catalog page
- Handcrafted pastel art aesthetic
- Local artwork SVGs and animation assets

Run locally:
1. Open a terminal in this folder
2. Run: npx http-server -p 3000
3. Visit http://127.0.0.1:3000/

The project is intentionally lightweight and uses local static assets so it can be served without a build step.
